# 🚔 Police Record Management System

A Python-based Police Record Management System that provides a unified interface for launching a web application, desktop speech-to-text application, and database management GUI. The project is designed to simplify police record management by integrating AI-powered transcription with database operations.

---

## 📌 Features

- 🔐 Secure Login Authentication
- 🌐 Launch Web Application
- 🖥 Launch Desktop Speech-to-Text Application
- 📁 Open Database Management GUI
- 🎤 AI-based Speech-to-Text Integration
- 📄 Record Management
- 🗃 Database Connectivity
- 👮 User-friendly Interface built with Tkinter

---

- Python 3.x
